# Локальные списки

Модуль хранит данные в браузерном хранилище устройства через `services/storage/local-store.js`.

Типы:
- `tasks` — «Хочу сделать»;
- `watchlist` — «Хочу посмотреть»;
- `wishlist` — «Мои хотелки»;
- `reminders` — разовые и повторяющиеся напоминания.

Основные операции: `getItems`, `addItem`, `updateItem`, `deleteItem`.
Для резервного копирования доступны `exportAllLists` и `importAllLists`.

Повторения напоминаний на этом этапе описываются частотой `none | daily | weekly | monthly` и интервалом. Этот модуль пока только хранит расписание: он не запускает системные уведомления и не гарантирует срабатывание, когда приложение закрыто.

Данные находятся только в локальном браузере и не синхронизируются между устройствами. Для синхронизации потребуется защищённый сервер и авторизация.
