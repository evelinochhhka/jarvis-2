# Клиентская часть

Здесь будет развиваться интерфейс JARVIS 2.

Планируемые каталоги:
- `app/` — запуск и навигация;
- `components/` — общие компоненты;
- `features/` — независимые пользовательские функции;
- `services/api/` — связь с сервером;
- `services/storage/` — абстракция локального и удалённого хранилища;
- `styles/` — стили.

Не переносить сюда код из текущего `index.html`, пока не подготовлена миграция с сохранением существующего поведения.
