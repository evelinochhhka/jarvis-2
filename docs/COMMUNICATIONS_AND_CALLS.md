# Коммуникации и звонки: требования и ограничения iOS

Дата фиксации: 2026-11-23

## Цель пользователя

JARVIS 2 должен помогать управлять собственными уведомлениями, официальными подключениями мессенджеров и доступными средствами звонков. Требования к чтению уведомлений Telegram/Instagram/TikTok и управлению обычными сотовыми вызовами остаются ограниченными системными API iOS.

## Ограничения iOS

iOS не предоставляет обычному стороннему приложению универсальный доступ ко всем уведомлениям других приложений и общий API для управления чужими звонками.

- JARVIS может создавать и управлять собственными уведомлениями после разрешения.
- Telegram Bot API не даёт боту доступ ко всем личным сообщениям. Telegram Business поддерживает отдельный сценарий для выбранных чатов.
- Instagram Messaging API ограничен профессиональными аккаунтами и разрешениями Meta.
- Для TikTok доступ к личным сообщениям и системным уведомлениям через подходящий публичный API не подтверждён.
- CallKit предназначен для звонков собственной VoIP-службы, а не для управления обычными сотовыми вызовами или звонками сторонних приложений.
- Не использовать парсинг интерфейсов, перехват сессий, сбор паролей или обход ограничений платформ.

Официальные источники:
- https://core.telegram.org/bots/features
- https://developers.facebook.com/docs/graph-api/reference/message
- https://developer.apple.com/documentation/callkit
- https://developer.apple.com/documentation/pushkit/responding-to-voip-notifications-from-pushkit

## Web Push для собственной PWA

Apple поддерживает Web Push для веб-приложений, добавленных на экран «Домой», начиная с iOS/iPadOS 16.4. Это позволяет JARVIS отправлять собственные уведомления, но не читать уведомления других приложений.

### Реализовано в коде

- Клиент проверяет Secure Context, Service Worker, Push API и режим установленного приложения на iOS.
- Разрешение запрашивается только после нажатия пользователем.
- Сервер предоставляет публичный VAPID-ключ.
- PWA создаёт подписку и отправляет её на сервер с Bearer-токеном.
- Сервер проверяет авторизацию и HTTPS endpoint, сохраняет до 20 подписок в локальном JSON-хранилище и отправляет контрольное уведомление.
- Удаление подписки доступно из интерфейса; устаревшие endpoints удаляются при ответах 404/410.
- Service worker отображает push-события и открывает приложение после нажатия.

### Что требуется для реальной доставки

- Задать VAPID-ключи и контакт в защищённых переменных окружения.
- Настроить API_ACCESS_TOKEN и HTTPS.
- Развернуть сервер на хостинге с постоянным диском для файла подписок.
- Установить PWA на экран «Домой» на iPhone/iPad и проверить доставку на реальном устройстве.

Генератор VAPID-ключей: `npm run generate:vapid-keys`. Приватный ключ нельзя добавлять в Git или клиент. Пока сервер и секреты не настроены, кнопка уведомлений сообщит, что сервер недоступен или push не настроен. Наличие подписки само по себе не означает, что напоминания уже доставляются.

### Что ещё не реализовано

- Планировщик персональных напоминаний с часовыми поясами, повторами, защитой от дублей и переносом расписания.
- Общая пользовательская база, отдельные аккаунты и привязка подписок к разным пользователям.
- Облачная синхронизация локальных списков и памяти между iPhone/iPad.
- Интеграции Telegram Business, Instagram Messaging API и VoIP-служба JARVIS.

## Фокусирование

PWA не имеет публичного API для прямого переключения системного Focus. Текущий мост запускает заранее созданные пользователем Apple Shortcuts. Запуск Shortcut не подтверждает, что режим действительно включился. App Intents/Focus Filters не являются универсальным API для произвольного переключения системных режимов.

Официальная инструкция: https://support.apple.com/guide/shortcuts/run-a-shortcut-from-a-url/apd624386f42/ios
