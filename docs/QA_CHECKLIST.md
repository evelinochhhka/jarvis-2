# Проверка JARVIS 2 перед публикацией

Ветка: `foundation/architecture`.

## Проверка в браузере
- [ ] Главная открывается без ошибок JavaScript.
- [ ] Все пункты бокового меню переключают разделы.
- [ ] На узком экране меню закрывается после выбора раздела.
- [ ] Можно добавить запись в каждый из трёх обычных списков.
- [ ] Записи остаются после перезагрузки страницы на том же устройстве и в том же браузере.
- [ ] Можно изменить название и заметку.
- [ ] Задачу можно отметить выполненной и вернуть в активное состояние.
- [ ] Запись можно удалить.
- [ ] Напоминание требует дату и время, сохраняет повторение и позволяет включать/выключать запись.
- [ ] Экспорт скачивает JSON с четырьмя списками.
- [ ] Импорт корректной копии восстанавливает данные после подтверждения.
- [ ] Импорт некорректного JSON не затирает текущие данные.
- [ ] Диалог показывает понятное сообщение, пока API не настроен.
- [ ] Service worker устанавливается на HTTPS и не кэширует API-ответы.

## Что нельзя считать проверенным автоматически
Исходники сохранены в GitHub, но реальный запуск в браузере и проверка на iPhone/iPad ещё не выполнены. До публикации нужно пройти этот список на целевом устройстве.

## Ограничения
Пока нет синхронизации, входа в аккаунт, серверного ИИ, системных уведомлений и голосового управления.


## Офлайн-режим
- [ ] После первой установки и загрузки всех ресурсов приложение открывается в авиарежиме.
- [ ] Навигация и основные разделы открываются без сети.
- [ ] Списки можно создавать, изменять, удалять и читать офлайн.
- [ ] Сетевой чат сообщает об отсутствии сети и не блокирует локальные функции.
- [ ] Локальные изменения сохраняются после закрытия и повторного запуска.
- [ ] После восстановления сети синхронизация не теряет и не дублирует записи.
- [ ] Локальная ИИ-модель и локальное распознавание речи проверены отдельно; без загруженной модели ассистент честно сообщает, что автономный ИИ недоступен.

## Вечерняя проверка заряда
- [ ] Проверить реальные показания заряда iPhone и iPad на поддерживаемой нативной сборке.
- [ ] Проверить передачу данных Apple Watch через companion-приложение.
- [ ] Проверить, какие публичные данные доступны об AirPods; не использовать private API.
- [ ] Не показывать вымышленные проценты при недоступности данных.
- [ ] Проверить индивидуальные пороги, время проверки, тихие часы и отключение устройства.
- [ ] Проверить локальное уведомление при выключенной сети и ограничения фонового выполнения iOS.


## Голосовая активация и Apple Watch
- [ ] Голосовой запуск через Siri Shortcut/App Intent проверен без ручного открытия PWA.
- [ ] На iPhone 13 Pro отдельно проверены доступные системные точки запуска; не предполагается наличие Action Button.
- [ ] При активном голосовом режиме локальное распознавание работает в авиарежиме.
- [ ] После принудительного закрытия приложения не заявляется доступность фонового wake-word.
- [ ] WatchOS-компаньон устанавливается и запускается на Apple Watch Series 6 с фактической версией watchOS.
- [ ] С часов можно начать голосовой ввод явным действием и получить подтверждение результата.
- [ ] Команды через WatchConnectivity синхронизируются при доступности связи и ставятся в очередь при её отсутствии.
- [ ] Команда не помечается выполненной до подтверждения iPhone/локального обработчика.
- [ ] Проверены короткие команды на русском и украинском.
- [ ] Проверено отображение статуса соединения и времени последней синхронизации.
- [ ] Не используется скрытая запись, private API или обход фоновых ограничений Apple.
