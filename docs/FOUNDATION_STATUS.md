# JARVIS 2 — статус основы

Дата обновления: 23 ноября 2026 года. Рабочая ветка: foundation/architecture.

Этот документ отделяет готовые исходники от функций, которые пока существуют только как планы. Наличие файла или экрана не означает, что функция уже проверена на физическом устройстве.

## Реализовано в исходном коде

### Общая логика Swift
- Общая библиотека JarvisCore для iOS и watchOS.
- Локальные JSON-хранилища очереди команд, пяти разделов рабочего пространства, истории диалога и подтверждённой памяти.
- Добавление, редактирование, отметка выполнения и удаление локальных записей.
- Разбор простых команд на русском и украинском.
- Разбор датированных напоминаний с явным временем: сегодня/завтра, ISO-дата, ежедневные/еженедельные/ежемесячные повторы.
- Команды без достаточных данных не отмечаются выполненными; напоминание без времени сохраняется без уведомления.
- Unit-тесты для хранилищ, обработки команд, редактирования записей и разбора напоминаний.

### iOS/iPadOS
- SwiftUI-оболочка с разделами диалога, списков, локальных файлов, памяти, Фокусирования, настройки ИИ и выбора голосов.
- Голосовой ввод после явного запуска, с обязательным on-device распознаванием, если оно поддерживается для выбранного языка.
- Локальная история диалога с удалением беседы.
- HTTP-клиент серверного ИИ; секрет провайдера остаётся на сервере.
- Выбор установленных системных голосов отдельно для русского и украинского; озвучивание ответа и кнопка остановки.
- Локальные уведомления для напоминаний, созданных в приложении, с попыткой перепланирования после редактирования.
- Siri App Intent открывает приложение и инициирует голосовой экран.
- Запуск пользовательских Apple Shortcuts для режимов Фокусирования.
- Локальная файловая полка: импорт через системный picker, копирование в Documents/JARVISFiles, переименование, удаление и системная отправка файлов.

### Apple Watch
- Отдельный watchOS target и интерфейс коротких команд.
- Передача через WatchConnectivity, очередь команд при недоступности iPhone и ограниченная защита от повторной обработки.
- Сохранение команд на iPhone через общий обработчик.
- Для датированных напоминаний iPhone пытается создать локальное системное уведомление; без даты/времени сообщает, что расписание не создано.

### Сервер и PWA
- PWA с четырьмя основными списками, локальным хранилищем и экспортом/импортом JSON.
- Локальная файловая библиотека PWA на IndexedDB: импорт нескольких файлов, список метаданных, переименование, скачивание и удаление; лимит 100 МБ на файл.
- Node.js API /api/v1/health и /api/v1/chat.
- OpenAI-compatible адаптер с конфигурируемым провайдером и моделью.
- Валидация запросов, лимит размера тела, тайм-аут, безопасные ошибки, CORS-настройка и базовый per-IP rate limit в памяти процесса.
- Опциональная Bearer-аутентификация `/chat` через `API_ACCESS_TOKEN`; PWA хранит токен в sessionStorage текущей вкладки, нативное приложение — в iOS Keychain.
- Ключ провайдера и VAPID private key не хранятся в клиенте или репозитории.
- Service worker кэширует только оболочку и статические ресурсы, исключая API.
- Web Push backend: VAPID public key endpoint, Bearer-защищённые endpoints регистрации/удаления подписок, JSON-хранилище на постоянном диске, контрольное push-сообщение и очистка устаревших endpoints. Генератор VAPID-ключей и проверка конфигурации добавлены.
- Серверный планировщик push-напоминаний: защищённые API списка/создания/удаления, постоянное хранилище, разовые и ежедневные/еженедельные/ежемесячные повторы с учётом IANA-часового пояса и DST; PWA синхронизирует локальные напоминания с сервером.

## Автоматические проверки

Проверки JavaScript и Swift запускаются через GitHub Actions. Нативный workflow собирает симуляторы iOS и watchOS и выполняет swift test для JarvisCore. Результат относится только к конкретному commit SHA. Актуальное состояние: [GitHub Actions](https://github.com/evelinochhhka/jarvis-2/actions). Если workflow ещё выполняется или был отменён, сборка не считается успешной.

## Что не завершено и требует внешних действий

1. **ИИ ещё не подключён в реальном приложении.** Нужен сервер в безопасной инфраструктуре, проверенный провайдер и ключ в серверном окружении. Внешний провайдер и его условия использования должны быть проверены ответственным взрослым.
2. **Нет полноценной пользовательской аутентификации API.** Добавлен общий статический Bearer-токен для одного владельца, но нет аккаунтов, ролей, ротации сессий или серверного управления устройствами. Это не готовая защита для публичного запуска.
3. **Нет облачной базы и синхронизации.** Локальные данные iPhone, iPad и часов пока не объединены в единое облачное хранилище.
4. **Нет полноценной локальной языковой модели.** Без интернета локальные списки, память, очередь и функции ОС работают, но свободный диалог с ИИ недоступен.
5. **ru m5 не восстановлен.** В репозитории нет исходных файлов старого голосового движка. Системные голоса Apple доступны как отдельный резервный вариант и не объявляются заменой ru m5.
6. **Нет фонового wake-word.** Обычное приложение iOS не может постоянно слушать произвольную кодовую фразу после закрытия.
7. **Внешние коммуникации не подключены.** Нет универсального чтения уведомлений Telegram/Instagram/TikTok или управления обычными сотовыми вызовами. Для сторонних сервисов возможны только официальные интеграции с соответствующими разрешениями.
8. **Push-напоминания реализованы в исходниках, но не развернуты.** Есть VAPID-подписки, контрольная отправка, серверный планировщик и синхронизация PWA-напоминаний. Для реальной доставки нужны секреты VAPID, Bearer-токен, HTTPS, постоянный диск и проверка на установленной PWA. Нет отдельных аккаунтов и общего облачного профиля.
9. **Файлы пока локальные.** В PWA файлы хранятся в IndexedDB браузера, в iOS — в Documents приложения. Нет облачной синхронизации, полнотекстового поиска, встроенного просмотра всех форматов и общей файловой полки между устройствами. Очистка данных сайта может удалить PWA-библиотеку.
10. **Нет физического тестирования и установки.** Нужны подпись приложения, provisioning, установка на iPhone 13 Pro, iPad A16 и Apple Watch Series 6, а затем проверка разрешений, микрофона, уведомлений и WatchConnectivity.

## Что считается завершением основы

Основа исходного кода считается подготовленной после прохождения JavaScript-тестов, Swift unit-тестов и сборок iOS/watchOS симуляторов. Полностью готовым к ежедневному использованию продуктом JARVIS 2 станет только после безопасного подключения сервера, установки и проверки на физических устройствах. Слияние рабочей ветки в main и развёртывание сервера требуют отдельного решения владельца проекта.
