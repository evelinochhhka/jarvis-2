# Тестовый запуск JARVIS 2 на iPhone/iPad

## Что даёт этот запуск

Тестовая версия публикует только PWA-интерфейс из ветки `foundation/architecture`. Она подходит для проверки экранов, навигации, локальных списков, заметок, локальных файлов и сохранения данных в браузере.

Это не нативная iOS-сборка и не подключённый ИИ. Пока отдельный API-сервер не развёрнут, диалог с ИИ, серверные напоминания и push-доставка не будут работать. Не вводите в тестовую версию секреты, пароли или чувствительные данные. Данные PWA хранятся локально в браузере этого устройства и не синхронизируются с iPhone/iPad автоматически.

## Однократная настройка GitHub Pages

1. Откройте настройки репозитория: https://github.com/evelinochhhka/jarvis-2/settings/pages
2. В разделе Build and deployment выберите Source: **GitHub Actions**.
3. Сохраните настройку. Ничего не нужно сливать в `main`.

## Запуск тестовой версии

1. Откройте https://github.com/evelinochhhka/jarvis-2/actions/workflows/pages-preview.yml
2. Нажмите **Run workflow**.
3. В поле Branch выберите `foundation/architecture`.
4. Запустите workflow и дождитесь зелёного статуса обоих этапов.
5. Откройте опубликованный URL из блока **deploy**. Ожидаемый адрес Pages: https://evelinochhhka.github.io/jarvis-2/ . Используйте именно URL, который покажет GitHub Actions.

На iPhone/iPad откройте ссылку в Safari. Для режима веб-приложения нажмите «Поделиться» → «На экран Домой», затем запускайте с новой иконки.

## Что проверить

- Открываются все разделы и меню.
- Можно создавать, изменять, отмечать и удалять записи в четырёх списках.
- После закрытия и повторного открытия PWA локальные записи остаются на этом же устройстве.
- Можно импортировать и удалять тестовый файл в разделе «Файлы».
- При отсутствии сервера приложение честно сообщает, что сервер недоступен; это ожидаемо для статического preview.

## Ограничения тестового preview

- Это публичная статическая веб-страница; не размещайте там секреты или персональные данные.
- Нет API, AI-провайдера, облачной синхронизации, push-планировщика и серверной памяти.
- Не проверяет микрофонный сценарий нативного приложения, системные голоса iOS, Apple Watch, Siri App Intents или Focus Shortcuts.
- Для настоящего нативного теста потребуется macOS с Xcode, подпись приложения и установка на устройства.
- Workflow запускается только вручную из `foundation/architecture`; автоматической публикации при каждом коммите нет.
