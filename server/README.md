# Серверная часть

Серверный слой будет предоставлять API для диалога, истории, памяти, пользовательских списков и напоминаний.

Требования:
- ключи ИИ-провайдеров только в переменных окружения;
- никакие секреты не передаются браузеру;
- проверка и ограничение входящих запросов;
- единый адаптер провайдера модели, чтобы его можно было заменить;
- хранение данных отдельно от бизнес-логики;
- приватные ответы API не кэшируются service worker.

Конкретный фреймворк и хостинг будут выбраны до реализации серверного кода, после проверки требований к развёртыванию и доступных секретов.
