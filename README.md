# JARVIS 2

Персональный двуязычный цифровой ассистент для iPhone, iPad и Apple Watch. Рабочее имя и интерфейс проекта можно менять без привязки к окончательному бренду.

## Уже подготовлено в репозитории

- PWA-интерфейс с навигацией, локальными списками, диалогом, настройками и экспортом/импортом резервной копии.
- Локальные разделы: «Хочу сделать», «Хочу посмотреть», «Мои хотелки» и «Напоминания».
- Нативная SwiftUI-основа iOS/iPadOS и companion target watchOS.
- Локальная история диалога и отдельная редактируемая память.
- Голосовой ввод с явным запуском и поддержкой русского/украинского языков при наличии on-device распознавания в iOS.
- Выбор системного голоса отдельно для русского и украинского ответов, прослушивание образцов и озвучивание ответов в нативном диалоге.
- HTTP-клиент нативного приложения для подключения к собственному серверу JARVIS.
- Серверный адаптер OpenAI-compatible API, по умолчанию настроенный на бесплатный маршрут Nemotron через OpenRouter.
- Проверка состояния сервера, ограничения размера запросов, тайм-ауты и базовый per-IP rate limit.
- Автоматические проверки JavaScript и Swift, сборка симуляторов iOS/watchOS через GitHub Actions.

## Текущие ограничения

Репозиторий содержит исходный код и конфигурацию, а не установленное приложение. ИИ не отвечает в приложении, пока сервер не развёрнут и провайдер не настроен. Ключ провайдера должен храниться только в серверном окружении, не в приложении и не в Git.

Нативную сборку нужно подтвердить в CI, затем отдельно подписать и установить на реальные устройства. Тестирование на iPhone, iPad и Apple Watch ещё необходимо. Исходный голос `ru m5` не восстановлен; он не заменён автоматически. Пользовательские голоса iOS являются резервными вариантами.

Пока нет полноценной аутентификации, облачной базы, синхронизации личных данных между устройствами и полноценного локального LLM. Не публикуйте сервер в интернете до настройки защищённого HTTPS, аутентификации и проверки приватности.

Ограничения iOS не позволяют обычному стороннему приложению постоянно слушать произвольную wake-фразу после закрытия приложения или читать все уведомления и управлять звонками других приложений.

## Структура

- `src/` — PWA-клиент.
- `server/` — Node.js API и адаптеры ИИ-провайдеров.
- `native/JarvisCore/` — общая Swift-логика и тесты.
- `native/iOS/` — iPhone/iPad-приложение.
- `native/watchOS/` — приложение-компаньон Apple Watch.
- `docs/` — архитектура, API, ограничения и план проверки.

## Локальные проверки

Требуется Node.js 20 или новее:

```sh
npm test
npm run check
```

Для Swift Core:

```sh
swift test --package-path native/JarvisCore
```

Для генерации и сборки Apple targets требуется macOS с Xcode и XcodeGen. См. [native/README.md](native/README.md).

## Рабочая ветка

Разработка ведётся в `foundation/architecture`. Pull request в `main` остаётся черновиком и не должен сливаться без отдельного подтверждения владельца проекта.
