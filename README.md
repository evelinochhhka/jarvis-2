# JARVIS 2

Персональный двуязычный цифровой ассистент для iPhone, iPad и Apple Watch. Рабочее имя и интерфейс проекта можно менять без привязки к окончательному бренду.

## Уже подготовлено в репозитории

- PWA-интерфейс с навигацией, локальными списками, диалогом, настройками и экспортом/импортом резервной копии.
- Локальные разделы: «Хочу сделать», «Хочу посмотреть», «Мои хотелки» и «Напоминания».
- Нативная SwiftUI-основа iOS/iPadOS и companion target watchOS.
- Локальная история диалога и отдельная редактируемая память.
- Голосовой ввод с явным запуском и on-device распознаванием русского/украинского, если оно поддерживается на устройстве.
- Раздельный выбор системных голосов для русского и украинского ответов, озвучивание и остановка речи.
- HTTP-клиент нативного приложения для подключения к собственному серверу JARVIS.
- Экспериментальный локальный ИИ для PWA через WebGPU: Qwen2.5 0.5B, генерация непосредственно в браузере без сервера; первая загрузка модели требует интернета, дальнейшая работа использует кэш браузера.
- Серверный OpenAI-compatible адаптер с настраиваемым провайдером и моделью для дополнительных серверных функций.
- Bearer-защита чата и push-подписок, хранение токена PWA только в сессии вкладки, хранение токена iOS в Keychain, генераторы серверного токена и VAPID-ключей.
- Валидация API, ограничения размера запросов, тайм-ауты, CORS, per-IP rate limit и Bearer-аутентификация защищённых маршрутов.
- Web Push backend и серверный планировщик напоминаний с повторами и часовыми поясами; требует настройки VAPID, Bearer-токена, HTTPS и постоянного диска.
- Команды Apple Watch с очередью доставки и передачей на общий локальный обработчик iPhone.
- Разбор простых русских и украинских команд, включая явные даты/время и повторы напоминаний.
- Нативное редактирование записей и перепланирование локальных напоминаний.
- Локальная файловая полка в iOS: импорт, переименование, удаление и отправка файлов.
- Локальная файловая библиотека PWA на IndexedDB: импорт нескольких файлов, переименование, скачивание и удаление (до 100 МБ на файл).
- Автоматические проверки JavaScript и Swift, сборки симуляторов iOS/watchOS через GitHub Actions.

## Текущие ограничения

Репозиторий содержит исходный код, а не установленное приложение. В PWA добавлен экспериментальный локальный чат на WebGPU: он не требует API-ключа или сервера, но требует совместимого браузера и первоначальной загрузки модели. На iPadOS 27 поддержку WebGPU предоставляет Safari, однако реальная загрузка модели и стабильность ещё не проверены на физическом iPad A16. Серверный ИИ остаётся отдельной необязательной возможностью; ключ провайдера хранится только в серверном окружении.

Серверный прототип получил общий Bearer-токен для защиты чата (если задан API_ACCESS_TOKEN), но пока не имеет отдельных аккаунтов, ролей, базы данных или облачной синхронизации. PWA хранит токен только в текущей вкладке, iOS — в Keychain. Это начальная защита, не замена полноценной пользовательской авторизации и защитного reverse proxy. Не публикуйте его в интернете и не используйте для личных данных до реализации защиты доступа и проверки приватности.

Нативную сборку нужно подтвердить в CI, затем отдельно подписать и установить на реальные устройства. Тестирование на iPhone, iPad и Apple Watch ещё необходимо. Исходный голос ru m5 не восстановлен; он не заменён автоматически. Системные голоса iOS являются отдельными резервными вариантами.

Нативный MLX-движок ещё не проверен на физическом устройстве; браузерный локальный движок является экспериментальным. Нет фонового wake-word, универсального доступа к уведомлениям Telegram/Instagram/TikTok или управления обычными сотовыми вызовами. Серверный планировщик push-напоминаний подготовлен, но без настроенных секретов и развёрнутого HTTPS-сервера доставка не работает. Облачная синхронизация списков/памяти и файловая полка между устройствами ещё не реализованы.

## Структура

- src/ — PWA-клиент.
- server/ — Node.js API и адаптеры ИИ-провайдеров.
- native/JarvisCore/ — общая Swift-логика и тесты.
- native/iOS/ — iPhone/iPad-приложение.
- native/watchOS/ — приложение-компаньон Apple Watch.
- docs/ — архитектура, API, ограничения и план проверки.

## Локальные проверки

Требуется Node.js 20 или новее:

\`\`\`sh
npm test
npm run check
\`\`\`

Для Swift Core:

\`\`\`sh
swift test --package-path native/JarvisCore
\`\`\`

Для генерации и сборки Apple targets требуется macOS с Xcode и XcodeGen. См. [native/README.md](native/README.md).

Подробный список реализованного и незавершённого: [docs/FOUNDATION_STATUS.md](docs/FOUNDATION_STATUS.md). Проверки сборки: [GitHub Actions](https://github.com/evelinochhhka/jarvis-2/actions).

## Рабочая ветка

Разработка ведётся в foundation/architecture. Pull request в main остаётся черновиком и не должен сливаться без отдельного подтверждения владельца проекта.
