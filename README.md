# JARVIS 2

Персональный двуязычный цифровой ассистент для iPhone, iPad и Apple Watch. Рабочее имя и интерфейс проекта можно менять без привязки к окончательному бренду.

## Уже подготовлено в репозитории

- PWA-интерфейс с навигацией, локальными списками, диалогом, настройками и экспортом/импортом резервной копии.
- Локальные разделы: «Хочу сделать», «Хочу посмотреть», «Мои хотелки» и «Напоминания».
- Нативная SwiftUI-основа iOS/iPadOS и companion target watchOS.
- Локальная история диалога и отдельная редактируемая память.
- Голосовой ввод с явным запуском и on-device распознаванием русского/украинского, если оно поддерживается на устройстве.
- Раздельный выбор системных голосов для русского и украинского ответов, озвучивание и остановка речи.
- HTTP-клиент нативного приложения для подключения к собственному серверу JARVIS.
- Серверный OpenAI-compatible адаптер с настраиваемым провайдером и моделью.
- Валидация API, ограничения размера запросов, тайм-ауты, CORS и базовый per-IP rate limit.
- Команды Apple Watch с очередью доставки и передачей на общий локальный обработчик iPhone.
- Разбор простых русских и украинских команд, включая явные даты/время и повторы напоминаний.
- Нативное редактирование записей и перепланирование локальных напоминаний.
- Локальная файловая полка в iOS: импорт, переименование, удаление и отправка файлов.
- Локальная файловая библиотека PWA на IndexedDB: импорт нескольких файлов, переименование, скачивание и удаление (до 100 МБ на файл).
- Автоматические проверки JavaScript и Swift, сборки симуляторов iOS/watchOS через GitHub Actions.

## Текущие ограничения

Репозиторий содержит исходный код и конфигурацию, а не установленное приложение. ИИ не отвечает в приложении, пока сервер не развёрнут и провайдер не настроен. Ключ провайдера должен храниться только в серверном окружении, не в приложении и не в Git.

Серверный прототип пока не имеет полноценной аутентификации, базы данных или облачной синхронизации. Не публикуйте его в интернете и не используйте для личных данных до реализации защиты доступа и проверки приватности.

Нативную сборку нужно подтвердить в CI, затем отдельно подписать и установить на реальные устройства. Тестирование на iPhone, iPad и Apple Watch ещё необходимо. Исходный голос ru m5 не восстановлен; он не заменён автоматически. Системные голоса iOS являются отдельными резервными вариантами.

Нет полноценной локальной языковой модели, фонового wake-word, универсального доступа к уведомлениям Telegram/Instagram/TikTok или управления обычными сотовыми вызовами. Push backend и облачная файловая полка ещё не реализованы.

## Структура

- src/ — PWA-клиент.
- server/ — Node.js API и адаптеры ИИ-провайдеров.
- native/JarvisCore/ — общая Swift-логика и тесты.
- native/iOS/ — iPhone/iPad-приложение.
- native/watchOS/ — приложение-компаньон Apple Watch.
- docs/ — архитектура, API, ограничения и план проверки.

## Локальные проверки

Требуется Node.js 20 или новее:

\`\`\`sh
npm test
npm run check
\`\`\`

Для Swift Core:

\`\`\`sh
swift test --package-path native/JarvisCore
\`\`\`

Для генерации и сборки Apple targets требуется macOS с Xcode и XcodeGen. См. [native/README.md](native/README.md).

Подробный список реализованного и незавершённого: [docs/FOUNDATION_STATUS.md](docs/FOUNDATION_STATUS.md). Проверки сборки: [GitHub Actions](https://github.com/evelinochhhka/jarvis-2/actions).
