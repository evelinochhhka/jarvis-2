# Нативная основа JARVIS 2

Эта папка содержит исходники iOS/iPadOS и watchOS. Репозиторий пока не является установочной сборкой: для установки на физические устройства потребуются подпись, provisioning profiles и проверка на самих устройствах.

## Состав

- `JarvisCore` — общие типы команд, двуязычный разбор, очередь, локальные списки, хранилище памяти и история диалогов.
- `iOS/JarvisIOSApp.swift` — SwiftUI-оболочка приложения и запуск приёмника команд Apple Watch.
- `iOS/JarvisConversationView.swift` — локальная история диалога, вызов локальной MLX-модели и озвучивание ответов.
- `iOS/JarvisMLXAIEngine.swift` — локальный движок Gemma 3 1B QAT 4-bit, загрузка весов с Hugging Face и генерация на устройстве.
- `iOS/JarvisAISettingsView.swift` — загрузка локальной модели и отображение прогресса.
- Остальные экраны обеспечивают локальные списки, память, файлы, голосовые настройки, команды Siri и связь с Apple Watch.

## Локальный ИИ

Приложение использует MLX Swift LM и модель `mlx-community/gemma-3-1b-it-qat-4bit`. Первая загрузка требует интернета; после загрузки веса остаются в кэше приложения, а генерация выполняется на устройстве. Внешний сервер, Ollama и ноутбук в цепочке генерации не используются.

Модель компактная, поэтому её ответы и скорость уступают крупным облачным системам. Реальную производительность, расход памяти и стабильность нужно проверить на физическом iPad A16. Успешная сборка симулятора не доказывает работу MLX на физическом устройстве.

## Голос и языки

- Распознавание речи запускается только после явного действия пользователя или системной Siri-команды.
- Приложение требует on-device распознавание; если выбранный язык не поддерживает его на устройстве, модуль сообщает об этом.
- Системные голоса iOS перечисляются на самом устройстве; отдельные голоса для русского и украинского можно выбрать.
- Исходный голос `ru m5` не восстановлен: старые локальные файлы отсутствуют в репозитории. Он не заменён автоматически.
- Фоновое произвольное wake-word при закрытом приложении не реализовано.

## Установка и проверка

На Mac с Xcode и XcodeGen из корня репозитория:

```sh
brew install xcodegen
xcodegen generate --spec native/project.yml --project native
swift test --package-path native/JarvisCore
xcodebuild -project native/JARVIS2.xcodeproj -scheme JARVIS2 -destination 'generic/platform=iOS Simulator' -configuration Debug CODE_SIGNING_ALLOWED=NO build
xcodebuild -project native/JARVIS2.xcodeproj -scheme JARVIS2Watch -destination 'generic/platform=watchOS Simulator' -configuration Debug CODE_SIGNING_ALLOWED=NO build
```

GitHub Actions выполняет Swift-тесты и сборки симуляторов. Установка на iPad требует подписанной сборки и физической проверки; CI не может установить приложение на личное устройство.

## Ограничения

- Нет фонового wake-word, полного доступа к уведомлениям Telegram/Instagram/TikTok и управления обычными сотовыми звонками.
- Нет синхронизации данных между устройствами и облачной базы.
- Голосовой движок `ru m5` пока не восстановлен.
- Apple Watch-компаньон не запускает большую языковую модель самостоятельно; локальная модель работает на iPad.
